# Security audit — WorkForce Management

**Date:** 2026-10-24 · **Auditor:** Claude (owner-reviewed) · **Commit:** branch `ccr-842b3a88-ddan6t` · **Target:** local production build (`next start`)
**Overall posture:** before 🔴 high risk (open admin) -> after 🟠 medium (single shared password, unverified on Netlify)

## 1. Scope & method
Surface: 9 routes, 18 `"use server"` exports (users, roster, tasks, settings), Google Sheets client, env vars (`GOOGLE_*`, `ADMIN_PASSWORD`, `AUTH_SECRET`, `AUTH_DISABLED`), no user-driven outbound requests.
Methods: code read, `grep`, git-history secret search, `npm audit --omit=dev`, curl + Playwright against a local production build (375px and 1280px).
Not tested: Netlify runtime (Proxy execution), load/DoS, Google-side IAM, the sheet's sharing settings.

- One shared password: anyone who knows it is fully trusted.
- The sheet itself is still editable by anyone you share it with directly.
